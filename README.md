## 快速开始
### 前置工作
1. 下载最新[Release](https://github.com/bbblllllocck/Canned-Emotions/releases)并且安装在你的安卓设备上
2. 在扫描页面添加你想要扫描的目录
3. 在API页面添加一个或多个从[Google AI Studio](https://aistudio.google.com/)中获得的API
（如果添加多个API可以自动轮换至有限额的那个）
（推荐使用免费层级的API）

4. 在数据库页面开始音频处理任务（此过程可能需要网络代理）
### 开始聆听
1. 回到开始页面，拉出屏幕底部的抽屉，长按随机按钮或者点击选定按钮来选定起始歌曲，然后长按开始按钮进行漫游播放。
2. 你也可以在对称检索模式下点击屏幕中间的专辑显示区域，在里面输入任意可以描述歌曲的文本，点击检索按钮，就可以开始聆听与描述近似的音乐（此过程可能需要网络代理）


> 要详细了解播放队列的逻辑以及算法板块，请参考[算法与播放列表]
>

## 它的原理是什么？

原理很简单，只是把音乐的音质降一降裁成80秒的片段，然后整个丢给Gemini Embedding 2生成向量， 然后存到 [ObjectBox](https://github.com/objectbox) 数据库里。等你想要的时候就拿文本或者什么玩意儿来生成一个向量，拿这玩意搜一搜，又或是直接拿已有的向量去查找近似的，再加点小算法修正一下结果，功能很简单。

## 它适合什么样的人？
如果你有一个庞大而且种类繁多的本地音乐库，并且想要在Android平台上拥有智能的播放体验，那么这个软件可能能为你带来一些新思路。

它可以帮助你更轻松地检索到能描述出来但是不知道具体名称的音乐，或者在听音乐时以听感为根基，建立一个更连贯多样的播放体验。

如果你想要更传统的本地音乐播放体验，诚意推荐 [Salt Player](https://github.com/Moriafly/SaltPlayerSource)，世界上最好的本地音乐播放器。
