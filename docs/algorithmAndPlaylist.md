# 播放队列的滑块
然后是播放队列。我引入了一个滑块。滑块和当前播放的歌曲之间的间隔就是云朵区（一个缓冲区），会显示你后面播放的音乐。如果你把滑块往下滑，这个区域就会变长。

处于缓冲区的歌曲在你执行切歌操作时不会被切歌惩罚降权。这个功能的初衷就是为了解决你看到的列表被刷新而产生的失落感。

使用过那些社交媒体的朋友们应该有印象：从后台切回B站，看到感兴趣的东西——马上自动刷新掉。这个功能就是为了避免这种悲剧

# 算法
以向量相似度为基准权重，算法模板可以对每首歌曲进行细致的加权降权，避免播放列表过于死板。

**不相关系数** 

这是原始权重惩罚的基准值，比如如果这个系数的值是0.2，经过专辑查重的计算要对后面的某首歌给予0.5个惩罚系数，那么对原始权重的影响就是0.2*0.5=0.1

这个值不建议调太高，因为基本所有音乐的相似度都会在0.7-0.9的区间。由于现在算法页面做的还不是很好所有我建议所有参数都在原有的默认模板上面修改。

**随机温度**

对最终进行完所有权重计算的歌曲进行softmax pick，略微打乱一下队列。温度越高，随机性越高。
